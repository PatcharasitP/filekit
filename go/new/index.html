วาง token ของ GitHub

หน้านี้ไม่จำ token ไว้ที่ไหนเลย ต้องวางใหม่ทุกครั้งที่เปิด และลืมเองเมื่อปิดแท็บหรือไม่ได้ใช้ 15 นาที เก็บ token ไว้ใน password manager แล้วคัดลอกมาวาง

ยังไม่มี token สร้างครั้งแรก 2 นาที
  1. เปิด หน้าสร้าง token ของ GitHub ชื่อกับอายุ 90 วันถูกเติมไว้ให้ ตรวจว่า Repository permissions ช่อง Contents เป็น Read and write
  2. Repository access เลือก Only select repositories แล้วเลือก golinks รีโปเดียว
  3. สิทธิ์อื่นปล่อย No access ทั้งหมด แล้วกด Generate token
  4. คัดลอก token เก็บใน password manager แล้ววางช่องข้างบน หน้านี้จะตรวจเองว่า token แคบพอ
  5. ตั้งเตือนในปฏิทินอีก 90 วัน token จะหมดอายุ ต้องสร้างใหม่
